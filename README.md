# MY WEB GIS MAP - LAB 6 FINAL

  

## Description 

This web map shows data on a interactive map of the United States specifically of Chicago, Houston, and Los Angeles using GeoJSON point data. Viewers are able to zoom in and out of the map along with being able to click on the provided points to view more information

It was built using Leaflet.js as part of GIS 5220/420 Lab 6. 

  

## Data Source 

The data used in this map comes from information within' the GeoJSON file The geographic data used in this map comes from the GIS 5220 Lab 6 instruction while the basemap is provided by OpenStreetMap

  

## Features 

- Interactive basemap with zoom and pan 

- GeoJSON that displays point features on the map

- Clickable popups that show point feature information such as population, state, notes

- Scale bar showing metric and imperial units 

  

## Technologies Used 

- HTML5, CSS3, JavaScript (all in one index.html file) 

- Leaflet.js 1.9.4 

- OpenStreetMap tiles
